Which tabular models handle text and images best?

Tabular models on 80 multimodal datasets. Text columns are embedded with frozen e5-small and images with frozen DINOv3-small, each reduced to 30 PCA components per column; ConTextTab reads raw text itself. Default hyperparameters, no bagging, 3 folds × 2 repeats, up to 10K training rows.

How to read this

Elo

Bradley–Terry fit over one battle per dataset and model pair, on the mean test error over folds. RandomForest is fixed at 1000. The interval is the 95% range over 1,000 bootstrap resamples of datasets.

Missing results are not imputed

Data

Every run is in multabench/leaderboard/models/<model>.csv. The tables here are plain CSVs in this Space's data folder: leaderboards.csv (one leaderboard per task and modality filter), per_dataset.csv and cost.csv.

Metrics

Test error is lower-is-better: 1 − ROC AUC for binary tasks, log loss for multiclass, RMSE for regression. Normalized error rescales each dataset to 0 (best model) – 1 (worst).

Hardware

Each run gets 8 CPUs and 32 GB. Tree models run on CPU (Xeon 8581C); the others on one H100 80 GB (Xeon 8481C).
